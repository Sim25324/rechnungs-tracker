Wichtig: Betrag, Datum und Aussteller werden automatisch aus der Datei ausgelesen (lokale Text-/Bilderkennung im Browser, keine Internetverbindung nötig) – das ist eine Lesehilfe, keine Garantie. Bitte immer kurz prüfen. Ob die ÖGK eine Leistung tatsächlich (anteilig) erstattet, kann dieses Tool nicht bestimmen – das hängt vom genauen Tarifposten ab und muss bei der ÖGK/Ihrer Versicherung nachgefragt werden.
Alle Daten bleiben lokal auf diesem Rechner gespeichert (IndexedDB im Browser) – keine Übertragung an einen Server, auch die Dokumentenanalyse läuft komplett offline. Jede Änderung wird sofort automatisch gespeichert. Trotzdem regelmäßig „Sichern“ nutzen, um ein Backup zu behalten – Browserdaten können z. B. beim Zurücksetzen des Browsers verloren gehen.
